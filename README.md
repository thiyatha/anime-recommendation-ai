# Anime Recommendation AI

Anime Recommendation AI is a multimodal Gradio app that recommends anime based on user preferences and optional image input.

The project combines three AI blocks:

- **NLP:** Keyword Matching, TF-IDF Similarity, and OpenAI preference extraction
- **ML Numeric Data:** Linear Regression and Random Forest Regression for anime score prediction
- **Computer Vision:** CLIP-based image matching for uploaded anime images or posters
